# Kai's Personal Website

Welcome to the repository for my personal website! This is a simple, modern landing page built to showcase my profiles, projects, and links.

**Live Website:** [Click here to visit](https://KaiTheGreat-123.github.io/personal-website/)

---

## Features
* **Modern Glass UI:** Frosted-glass containers with subtle blurs and border styling.
* **Live Clock:** A real-time updating digital clock widget in the corner.
* **Social Links:** Quick access to my GitHub, Reddit, YouTube, and Stardance projects.
* **Interactive Easter Egg:** A hidden surprise button for visitors.

---

## Built With
* **HTML5** - Page structure and layout.
* **CSS3** - Flexbox layout, glassmorphism filters, and hover animations.
* **JavaScript** - Live system clock functionality.
* **FontAwesome** - Scalable brand icons.
